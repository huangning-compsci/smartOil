## git提交规范：
1. 自己创建一个branch写代码，命名格式为"名字缩写_dev",例如"Hn_dev"
2. 完成一个功能后先上传到自己的分支以保存
3. 合并功能由hn/fg实现，其他人只负责提交代码和合并请求
4. 必须先同步main分支再开发
